Suggested rewrite

The sharper story

Most AI writing tools optimize for first drafts. This system optimizes for publishable technical content.

The project started from a concrete problem: newsletters are only useful when the sources are credible, the explanation is coherent, the code examples run, and the final layout survives mobile reading. A generic prompt chain can produce text, but it cannot reliably enforce all four constraints.

The solution is a purpose-built agent framework. A manager agent coordinates research, writing, editing, retrieval planning, and code validation while preserving explicit handoffs between each stage. Instead of hiding work inside a broad orchestration library, the system keeps each operation inspectable: retrieve sources, score them, draft the narrative, generate framework-aware examples, execute those examples in a sandbox, and only then export the finished newsletter.

The strongest portfolio angle is not “I used agents.” It is “I built a production-grade content system where quality is a blocking gate.” That framing highlights systems thinking, applied LLM architecture, practical QA, and the discipline to reject output that merely looks plausible.
